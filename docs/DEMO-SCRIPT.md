# ProofClock Demo Script

Target duration: **220 seconds**. Hard ceiling: **under 240 seconds**.

## 0:00-0:20 — Thesis

Open the clean production domain in a signed-out browser.

Say: “A legal clock usually fails before the arithmetic: the wrong event gets chosen. ProofClock makes that choice visible. Gemini may find candidate evidence, but a person binds the trigger and deterministic code computes every date.”

## 0:20-0:55 — First live input

Select **Cheque dishonour**.

Type live:

- Bank information received: `18-07-2026`
- Demand notice dispatched: `02-08-2026`

Pause so both values are readable. Point to the notice boundary: **17 Aug 2026**.

## 0:55-1:20 — Edge case first

Show that payment, cause-of-action, and complaint rows remain **UNBOUND**.

Read: “No confirmed record of receipt by the drawer. Dispatch does not bind receipt.”

Say: “This is not a generic error. It names the missing artifact and blocks every dependent result instead of guessing.”

## 1:20-1:45 — Local recomputation

Type live:

- Demand notice received by drawer: `20-08-2026`

Show the immediate client-side chain:

- 04 Sep 2026
- 05 Sep 2026
- 05 Oct 2026

Say: “No second model call happened. Every row shows its provision, input, operation, and caveat.”

## 1:45-2:10 — Provenance

Open the reviewed source excerpt for section 138(c). Point out:

- Third-party structured mirror label.
- Retrieval date.
- Gazette/official-text precedence warning.
- Live check button and snapshot fallback.

## 2:10-2:40 — Show the GenAI boundary

Type live in the evidence box: `The return memo was received on 18 Jul 2026.`

Acknowledge the Google disclosure and run extraction. Review the exact quote, then click **Review and bind**.

Open **Inspect Gemini prompt and guard**. Show the closed enum, JSON schema, raw response, accepted candidate, and any rejected candidates.

## 2:40-3:15 — Prove the engine is dynamic

Select **RBI Ombudsman 2026**.

Type live:

- Complaint to regulated entity: `01-07-2026`
- Last communication: `10-08-2026`

Show later-of selection on 10 Aug and the 90-day output on **08 Nov 2026**. Mention that RBI's official 2026 FAQ replaced the 2021 scheme and that ProofClock stops at COVERAGE LIMIT for dates before 1 July 2026.

## 3:15-3:40 — Close with architecture and evidence

Open **Method**.

Show Extract → Bind → Compute, the no-retention boundary, exact integration file map, and legal-source distinction.

Close: “ProofClock does not answer ‘am I in time?’ It shows what a selected rule computes from a selected, evidenced event—and refuses to invent the event that matters most.”
